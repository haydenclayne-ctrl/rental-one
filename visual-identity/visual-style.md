# Visual Style

## Photography

Documentary, not stock.

**Yes:** real crews and equipment on active sites · low-angle hero shots · dawn/dusk steel-blue light · order in frame (staged yards, aligned fleets, clean sites) · wide establishing shots paired with close texture.

**No:** stock handshakes, models pointing at clipboards, warm filters/HDR/vignettes, cluttered or unsafe or unbranded jobsites.

**Treatment:** full color runs cool and slightly desaturated (−10 to −20%). Duotone (covers, dividers) maps shadows → Midnight `#061024`, highlights → Steel Blue `#4F6DA8`. Text zones over photos get a 40–60% navy scrim.

## Graphic devices

- **The Chamfer** — 45° cut corners drawn from the logo's octagonal letterforms. Cards, buttons, photo masks. One or two corners, never all four.
- **The Keyline** — bold single-weight frame echoing the logo's border. Frames feature content; elements may break it deliberately, like the ONE box does.
- **The Plate** — mono-set data blocks styled like equipment ID plates (`UNIT R1-0448 · 20FT · CLIMATE`). Specs, stats, figure labels.

**Pattern:** only a fine blueprint grid (Steel Blue at 8–12% opacity on navy) on large fields — trade-show walls, cover interiors. No hazard stripes, no textures, no gradients beyond navy→midnight.

## Iconography

Geometric line icons, 24 px grid, 2 px stroke, square terminals, 45° corner cuts where a radius would normally appear. One color only (navy on light, white on navy). No filled icons, no rounded friendly sets, no emoji.

## Layout & grid

- 12-column grid, 24 px gutters, margins ≥6% of page width
- 8 pt spacing system — every space a multiple of 8
- Hard column alignment; centered layouts only for covers and dividers
- Minimum 30% empty space; one idea per spread, one focal point per layout
- If a layout needs a third typeface, a second accent, or a fourth element to work — it doesn't work
