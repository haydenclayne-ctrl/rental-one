# Rental One — Brand Guidelines

Source of truth for the Rental One brand. Rental One is an operating company of **Cotton Co** (repo: `haydenclayne-ctrl/cotton-co`), which is owned by **High Cotton Capital** (repo: `haydenclayne-ctrl/high-cotton-capital`). This repo stands alone — Rental One keeps its own identity and never borrows Cotton Co's black/gold or HCC's marks.

## What Rental One is

A project support company: equipment rentals, temporary infrastructure, labor solutions, logistics support, and FF&E services — from mobilization through project completion. Positioning is **mission support, not equipment rental**. Serves commercial construction, industrial, manufacturing, general contractors, government, healthcare, education, and corporate facilities.
